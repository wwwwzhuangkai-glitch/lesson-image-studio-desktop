# UI Workbench

## 1. 设计目标

本轮 UI 的目标不是“把功能排出来”，而是把 Lesson Image Studio 做成单屏工作台。

参考图的共同语言已经落到当前实现里：

- 固定应用壳
- 左侧稳定导航或版本轨
- 中间主工作区
- 右侧上下文检视器
- 次级信息收进抽屉
- 纵向节奏压缩，避免页面无限下拉

## 2. 页面骨架

### OwnerEntryPage

- 用于进入工作台，而不是工作台本体
- 结构：
  - 左：产品说明与能力标签
  - 右：打开 `Owner` 的表单
  - 下：最近打开

### OwnerOverviewPage

- 当前 `Owner` 下的多图管理桌面
- 结构：
  - 左栏：品牌、当前 `Owner`、主导航、底部工具入口
  - 顶栏：页面标题、轻量状态、整包发布占位
  - 主区：摘要条 + 图片项矩阵
- 图片项卡片以缩略图识别为主，状态辅佐
- 卡片动作只保留：
  - 进入编辑
  - 导入底图
  - 复制起点
  - 删除
  - 上移/下移

### ImageEditorPage

- 当前单图工作台
- 结构：
  - 左：`VersionTree`
  - 中：`CanvasWorkbench`
  - 右：固定检视器
- 检视器常驻 5 类核心动作：
  - 提示词
  - 参数设置
  - 定稿
  - 导出
  - 发布
- 模板库在检视器底部折叠，不弹窗

### UtilityDrawer

- 统一承载三类次级信息：
  - 任务
  - 事件
  - 回收站
- 入口放左栏底部
- 抽屉本身在右侧出现
- 内部通过 tab 切换，不使用多个并行浮层

## 3. 组件职责

- `CanvasWorkbench`
  - 画布展示
  - 前后对比
  - 局部框选
  - 画布尺寸提示
- `VersionTree`
  - 版本树展示
  - 小缩略图 + 时间 + 状态
  - 不承载编辑参数
- `UtilityDrawer`
  - 跨页共享的次级面板
- `NotificationCenter`
  - 只显示高优先级短消息

## 4. 交互收纳规则

- 任何围绕“当前图片”的主操作，优先放右侧检视器
- 任何围绕“画布本身”的局部操作，优先放画布上方迷你工具条
- 任何跨图片项、跨页面的辅助信息，优先放 utility drawer
- 模板属于“可选助力”，不是首屏主角，因此默认折叠

## 5. 后续前端扩展建议

如果下一轮继续优化，优先顺序建议是：

1. 优化总览页卡片的缩略图裁切与高亮反馈
2. 补 UtilityDrawer 与编辑页的交互动效
3. 给版本轨加入更明确的当前定稿视觉标识
4. 做前端按路由拆包，压低首屏 chunk

## 6. 下一阶段 UI 重构边界

下一阶段允许大改：

- 整体视觉语言
- 组件编排
- 卡片密度
- 检视器布局
- 主题表现
- 图标、动效、间距、层次

下一阶段不允许回退：

- 不能把工作台做回长网页
- 不能让编辑页失去左版本轨 / 中画布 / 右检视器的主结构
- 不能把次级信息重新拆成多个独立小浮层
- 不能为了视觉打磨而弱化数据边界和版本边界

下一阶段还会新增一个正式 `SettingsPage`，但它属于未来规划，不是当前已经存在的页面。
