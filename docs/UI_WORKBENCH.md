# UI Workbench

## 1. 设计目标

Lesson Image Studio 的页面首先应该像“工作台”，而不是“展示页”。

当前 UI 的核心目标是：

- 固定应用壳
- 单屏工作流
- 左侧稳定导航或版本轨
- 右侧主工作区
- 双图对照优先于单画布检视
- 底部控制台承载连续操作
- 次级信息收进统一抽屉
- 尽量压缩纵向滚动

## 2. 当前页面骨架

### OwnerEntryPage

- 用于进入工作台，而不是工作台本体
- 结构：
  - 左：产品说明与能力标签
  - 右：打开 `Owner` 的表单
  - 下：最近打开

### OwnerOverviewPage

- 当前 `Owner` 下的多图管理桌面
- 结构：
  - 左栏：品牌、当前 `Owner`、主导航、底部工具入口
  - 顶栏：页面标题、轻量状态、整包发布占位
  - 主区：摘要条 + 图片项矩阵
- 图片项卡片以缩略图识别为主，状态辅佐
- 卡片动作只保留：
  - 进入编辑
  - 导入底图
  - 复制起点
  - 删除
  - 上移/下移

### ImageEditorPage

- 当前单图工作台
- 结构：
  - 左：版本轨与当前选中上下文
  - 右上：`CanvasWorkbench` 双图对照区
  - 右下：紧凑控制台
- 左栏只承载导航与上下文：
  - `VersionTree`
  - 当前选中版本信息
  - 定稿状态
  - 任务 / 事件 / 回收站 / 模板入口
- 双图对照区遵守“选中即输入”：
  - 基准图显示左栏当前选中的版本
  - 结果图显示当前选中版本的最近直接子版本，优先显示基于它的最近任务产物
  - 没有结果时展示明确空态
  - 基准图工具条承载矩形框选、清除、显示 / 隐藏选区
  - 结果图只负责查看输出，不承担 mask 编辑
- 控制台常驻 3 类核心动作组：
  - 提示词
  - 生成参数
  - 动作按钮
- 模板库当前不再嵌在编辑页主区里
- 控制台只保留一个“打开模板抽屉”的入口按钮

### SettingsPage

- 当前的本地设置中心
- 结构：
  - 顶栏：返回按钮 + 全局 `AppTopbar`
  - 主区：单列卡片堆
- 当前分区：
  - 密钥
  - 外观
  - 默认参数

### UtilityDrawer

- 当前统一承载四类次级信息：
  - 任务
  - 事件
  - 回收站
  - 模板
- 入口放左栏底部
- 抽屉本身在右侧出现
- 内部通过 tab 切换，不使用多个并行浮层

## 3. 当前关键组件职责

- `CanvasWorkbench`
  - 基准图 / 结果图双图展示
  - 基准图矩形框选
  - 选区显示 / 隐藏
  - 棋盘格 / 纯色背景切换
  - 原图尺寸提示
- `VersionTree`
  - 版本树展示
  - 小缩略图 + 时间 + 状态
  - 不承载编辑参数
- `UtilityDrawer`
  - 跨页共享的次级面板
  - 当前也承载模板浏览和模板载入
- `NotificationCenter`
  - 只显示高优先级短消息

## 4. 交互收纳规则

- 任何围绕“当前图片”的主操作，优先放底部控制台
- 任何围绕“基准图本身”的局部操作，优先放基准图面板工具条
- 结果图面板只负责查看结果，不承担 prompt、参数或 mask 编辑
- 任何跨图片项、跨页面的辅助信息，优先放 `UtilityDrawer`
- 模板属于“可选助力”，不是首屏主角，因此当前放在 `UtilityDrawer` 的 `templates` tab
- 未来允许继续调整模板入口，但不能让它重新挤占编辑页主工作流

## 5. 当前结构里哪些能改

- 视觉语言可以继续深化
- 卡片密度可以继续调整
- 控制台的排版和层级可以继续优化
- 总览页和编辑页的布局细节可以重做
- 模板入口未来可以调整位置

## 6. 当前结构里哪些不能改

- 不能把工作台做回长网页
- 不能让编辑页失去左版本轨 / 双图对照 / 底部控制台的主结构
- 不能把 prompt、参数、导出、发布重新塞回左版本轨
- 不能让结果图面板承担 mask 编辑
- 不能把次级信息重新拆成多个独立小浮层
- 不能为了视觉打磨而弱化数据边界和版本边界
- 不能擅自新增第 5 个正式页面

## 7. 下一阶段 UI 方向

下一阶段的 UI 重点不再是“新增页面”，而是：

1. 继续打磨 4 页的结构感和现代感
2. 让 `SettingsPage` 从“已有设置页”演进成更成熟的本地设置中心
3. 为多 provider 接入预留清晰的设置入口，但不把编辑页做成 provider 配置台
